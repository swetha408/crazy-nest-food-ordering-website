# 🍗 CRAZY NEST – Food Ordering Website

## 📌 About the Project
CRAZY NEST is a responsive food ordering website inspired by popular online food delivery platforms. It allows users to browse food items, add products to a cart, and place demo orders through a simple interface.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Local Storage

## ✨ Features
- Interactive food menu and categories
- Food search functionality
- Add, remove, and update cart items
- Cart data saved using Local Storage
- Checkout form with customer details
- Order summary and delivery fee calculation
- Cash on Delivery and UPI Demo payment options
- Order confirmation with generated order ID
- Responsive layout for mobile screens

## 💻 How to Run the Project
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server or your browser.
4. Explore the CRAZY NEST website.

## ⚠️ Note
This is a frontend demonstration project. UPI is a demo option only. No real payments or actual food deliveries are processed.
